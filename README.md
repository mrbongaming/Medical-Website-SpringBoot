# Website đặt lịch khám An Tâm

Frontend React của một bệnh viện có nhiều cơ sở, dùng dữ liệu demo liên kết và lưu trong trình duyệt. Giao diện xanh dương–trắng gồm tìm cơ sở/bác sĩ, đặt lịch, lịch sử khám, bệnh án và quản trị/thu tiền mô phỏng.

- [Chạy frontend, tài khoản demo và hướng dẫn kiểm thử](frontend/README.md)
- [Chạy backend Spring Boot](backend/README.md)

```powershell
cd frontend
npm ci
npm run dev
```

Backend hiện là ứng dụng Spring Boot với cấu hình CORS; frontend chưa gọi API nghiệp vụ. Đợt cập nhật này không thay đổi backend.
